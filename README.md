## 🎮 Game Score System

### Description
A Java-based score management system designed to handle player data, calculate scores, and display rankings.

The project focuses on managing dynamic user input and processing data to create a simple game-like ranking system.

### Features
- Create and manage players
- Add and update scores
- Calculate rankings
- Display player statistics
- Handle user input dynamically

### Concepts Practiced
- Object-Oriented Programming (OOP)
- Classes and Objects
- Methods
- Data structures
- Input validation
- Sorting algorithms

### Technologies
- Java
- Java Standard Library
